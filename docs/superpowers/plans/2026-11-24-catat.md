# Catat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Aplikasi desktop portabel (Linux dulu) untuk toko perikanan: mencatat kas dan stok per kiriman dengan stok lama keluar dulu, grafik, ekspor XLSX/PDF, login dengan hak akses, foto barang.

**Architecture:** Tauri 2. Semua aturan (sesi, hak akses, stok, kas) ada di crate Rust sebagai fungsi biasa yang menerima `&Connection` dan `&Sesi`, sehingga bisa diuji dengan SQLite di memori. Perintah Tauri hanya pembungkus tipis: ambil state, periksa sesi, panggil fungsi inti. Tampilan Vue hanya memanggil perintah dan menampilkan hasil. Kedua ekspor (XLSX, PDF) memakai satu bentuk data `Laporan`.

**Tech Stack:** Rust (tauri 2, rusqlite `bundled`, argon2, chrono, serde, thiserror, rand, image, rust_xlsxwriter, printpdf 0.7, zip, tauri-plugin-dialog) · Vue 3 + TypeScript + Vite + vue-router + pinia + Tailwind 4 + shadcn-vue + vue-echarts · pnpm · vitest.

**Spec:** `docs/superpowers/specs/2026-11-24-catat-design.md` (baca sebelum mengerjakan tugas mana pun).

## Global Constraints

- Target: Linux. Tidak ada jalur/perintah khusus Linux di kode aplikasi; jalur dibentuk dengan `std::path`.
- Folder data = `data/` di sebelah program: `catat.db`, `foto/`, `cadangan/`. Tidak pernah diam-diam pindah ke tempat lain.
- SQLite: `journal_mode=DELETE`, `foreign_keys=ON`. Skema lewat migrasi bernomor.
- Uang: `i64` Rupiah. Jumlah barang: `i64` per seperseribu satuan (`1000` = 1 satuan). Tanggal: teks `YYYY-MM-DD`. Waktu: teks ISO-8601 waktu lokal.
- Setiap fungsi inti yang membaca/menulis data menerima `&Sesi` dan memanggil `akses::wajib(...)` lebih dulu. Tampilan tidak pernah menjadi satu-satunya penjaga.
- Tanpa hak `lihat_harga_beli`, field harga beli / nilai stok / laba bernilai `None` dari Rust.
- Tidak ada `DELETE`/`UPDATE` diam-diam pada transaksi stok dan kas otomatis: yang ada "batal". Setiap tambah/ubah/batal menulis `log_aktivitas`.
- Setiap operasi yang menyentuh lebih dari satu tabel berjalan dalam satu transaksi SQLite.
- Teks antarmuka dan pesan galat: bahasa Indonesia sehari-hari. Format angka `id-ID` (`Rp 385.000`, desimal koma).
- Kata sandi minimal 8 karakter, Argon2id. Tanpa akses jaringan. CSP ketat, capabilities minimal.
- Nama perintah Tauri = nama fungsi Rust (snake_case). Galat ke tampilan berbentuk `{ kode, pesan }`.

## Review Focus

1. Folder program tidak bisa ditulis → pesan jelas saat mulai, bukan crash atau pindah lokasi. (Task 2)
2. Penjualan yang gagal di tengah (stok kurang, hanya tersisa kiriman kedaluwarsa, kiriman dibatalkan) → tidak ada baris yang tersimpan sebagian; pesan menyebut barang dan sisa yang ada. (Task 7)
3. Angka diketik gaya Indonesia (`385.000`, `0,5`, `1.250,75`) atau kosong/negatif → terbaca benar atau ditolak dengan pesan, tidak jadi 385 atau NaN. (Task 11)
4. File pulihkan yang rusak atau bukan cadangan Catat → ditolak dan data yang ada tidak tersentuh. (Task 10)
5. Foto yang bukan gambar, rusak, atau sangat besar → ditolak dengan pesan, tanpa file yatim di `data/foto/`. (Task 4)
